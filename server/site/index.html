See the tags and ads behind any website

Superpixel is a free, open-source Chrome extension for competitor research. Type a domain or scan the tab you are on. A side panel lists every marketing, ads and analytics tag on the site, then pulls the ads pointing to that domain from public ad transparency libraries. It all runs in your own browser.

Two layers, one side panel

Point Superpixel at a domain and it answers two questions: what is installed on the site, and what is the company advertising right now.

B

Layer B: running ads

Advertisers and ads from public ad transparency libraries that point to the domain, so you can see what a competitor is actually running. Each library is queried in parallel and results stream into the panel as they arrive.

Every ad carries a label for how sure Superpixel is that it belongs to the scanned domain:

confirmed
The landing page or display URL is on the domain or one of its subdomains.
advertiser
From an advertiser account with at least one confirmed ad, but this ad's landing page was not checked or points elsewhere.
keyword
Only matched a keyword search for the domain or brand name. The landing page is not on the domain.
name
Only found through an advertiser name search, for libraries such as Snap that have no keyword search.

In the side panel

  • Scan a domain or the current tab. Type example.com and click Scan, or click Current tab.
  • Only confirmed. One switch hides everything except ads whose landing page points back to the scanned domain.
  • Export as JSON. Settings has "Export last scan as JSON" for the full result.
  • Local cache. Reopening the panel shows your last scan. Rescan forces a fresh pull.
  • Honest statuses. When a platform changes its response format, its card says "changed" instead of quietly reporting no results.
  • No build step. Manifest V3 and plain JavaScript you can read.

Deep links for the rest. Pinterest, X, Apple and Snap political ads have no scrapeable API, so Superpixel gives you a direct link to each library instead.

Optional fallback. These are unofficial or undocumented endpoints that platforms can change at any time. You can add a SearchAPI.io key as a fallback for when a scraper breaks.

Coverage varies. No ads in a library does not mean a competitor is not advertising there, only that nothing was found within that library's coverage and your request limits.

Install

Superpixel is not in the Chrome Web Store yet. You install it from the source:

  1. Clone the repository, or download the ZIP and unzip it. 
    git clone https://github.com/PiotrZapolski/superpixel.git
  2. In Chrome, open chrome://extensions.
  3. Turn on "Developer mode" (top right).
  4. Click "Load unpacked" and select the cloned repository folder.
  5. Pin the Superpixel icon to your toolbar.
  6. Click the icon to open the side panel.

What it needs

  • A Google account signed in to the same Chrome profile, for Google Ads Transparency search. Without it the Google card shows "needs you" with a sign-in link.
  • Facebook login is optional, but it improves Meta Ad Library results.
  • No account for the other libraries. Just an internet connection and a normal Chrome profile.

Privacy

Everything runs in your browser. Scans go straight from your machine to the public ad libraries, and results are stored only in your browser's local extension storage.

If you add a SearchAPI key, it stays in chrome.storage.local and is sent only to searchapi.io as a fallback request.

The only data that can ever reach a Superpixel server is the opt-in remote debug log. The first time the panel opens, it asks "Help fix broken scans?". Nothing is sent unless you click "Send logs".

If you say yes, each scan sends one batch to superpixel.run with a random install ID, the extension version, a scan ID, the scanned domain, the debug log's warnings and errors, and each platform's final status line. Never settings, keys, ads or page content. Turn it off anytime in Settings, Debug.
